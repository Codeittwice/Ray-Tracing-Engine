Know where the sun lands before you cut the mirror.

A Monte Carlo ray tracer for solar cookers and concentrators. Load a dish, a box, a trough or your own STL, set the sun, and read the flux on the receiver in watts per square metre.

Built for the parts of a cooker that matter.

Optics

Analytic paraboloids, spheres, planes and general quadrics for clean designs. Cylindrical paraboloids for troughs. Triangle meshes from STL or OBJ for anything you drew in CAD, with a scale factor for millimetre files.

Materials

Perfect mirrors for reference, real mirrors with reflectance and Gaussian slope error, dielectrics with a Fresnel split, Beer–Lambert absorption and Sellmeier dispersion for BK7 or fused silica, and absorbers.

Sun

A uniform pillbox disc, or the Buie 2003 sunshape with a circumsolar ratio between 0.02 and 0.10 for realistic aureole. Direct normal irradiance in W/m², and any sun direction.

Output

An interactive 3-D view with sampled ray paths and a heatmap on the receiver, plus a flux analysis panel with line plots. Or run headless from the command line and get a CSV flux map, a JSON summary and an OBJ of the scene.

Checked against physics, not screenshots

Twelve validation tests run on every build. A few of them:

  • T5Rays reflected by a paraboloid converge within 0.1 mm of the focus.
  • T6A perfect mirror conserves energy to better than 1%.
  • T8The BVH returns the same hit as brute force on 200 random scenes.
  • T9Reflected plus transmitted energy equals one at every incidence angle, to 1e-12.
  • T10Focal spot size matches the analytic formula within 5%.
  • T12A scene file survives a save-and-load round trip byte for byte.

A scene is one JSON file.

Materials, elements, receiver and sun in plain text. Version it with your design, share it with a colleague, or generate a hundred variants from a script and trace them headless overnight.

Units are metres, watts and degrees throughout. Wavelengths, when you need them, are in nanometres.

{
  "scene": {
    "name": "Parabolic dish",
    "sun": {
      "direction": [0, 0, -1],
      "dni_wm2": 1000,
      "sunshape": { "type": "buie", "chi": 0.05 }
    },
    "materials": [
      { "id": "alu", "type": "real_mirror",
        "reflectance": 0.85, "slope_error_mrad": 2.0 }
    ],
    "elements": [
      { "name": "dish", "material": "alu",
        "surface": { "type": "paraboloid",
                     "focal_length_m": 0.6,
                     "aperture_radius_m": 0.5 } }
    ],
    "receiver": {
      "surface": { "type": "plane",
                   "half_width": 0.05, "half_height": 0.05 },
      "grid": { "nx": 64, "ny": 64 },
      "transform": { "translation": [0, 0, 0.6] }
    }
  },
  "trace": { "n_primary_rays": 500000, "max_bounces": 8 }
}

Get started.

Download the zip, unpack it anywhere, and open an example scene. The interactive window needs a desktop session. Headless mode runs anywhere, including a CI job.

Building from source needs Visual Studio 2025, CMake 4, Ninja and vcpkg. The first configure compiles Polyscope and Assimp and takes a while.

Open a scene in the viewer

scrt_app.exe examples\parabolic_dish.json

Trace headless and export

scrt_app.exe examples\parabolic_dish.json --headless --rays 500000 --out results\

Build from source

cmake --preset release
cmake --build --preset release --parallel
ctest --test-dir build/release --output-on-failure
